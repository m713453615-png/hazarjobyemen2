# قائمة تجهيز المتاجر

## Google Play
- إنشاء حساب مطور باسم المالك القانوني.
- تثبيت اسم الحزمة `com.hazarjob.app`.
- إنشاء Upload Key وحفظ نسخة احتياطية آمنة.
- إضافة أسرار التوقيع إلى مستودع GitHub الخاص.
- تشغيل Workflow لإنتاج AAB موقع.
- رفع أيقونة 512x512 وصورة Feature Graphic ولقطات الهاتف.
- إكمال App Access وData Safety وContent Rating والإعلانات.
- إضافة سياسة الخصوصية ورابط حذف الحساب.
- إرسال النسخة إلى Internal testing أولاً.

## Microsoft Store
- إنشاء حساب Partner Center باسم المالك أو النشاط.
- حجز اسم `Hazar-Job.com`.
- اختيار تقديم EXE/MSI أو إنشاء MSIX.
- استضافة المثبت على رابط HTTPS ثابت إذا تم استخدام EXE.
- إضافة الشعارات واللقطات والوصف وسياسة الخصوصية.
- تشغيل Windows App Certification Kit عند توفره.
- إرسال الحزمة للاعتماد فقط بعد أمر المالك.

## حماية نسخة المالك
- لا تُرفع نسخة Windows Owner إلى مستودع عام.
- يبقى مفتاح API وكلمة مرور المالك خارج الكود والمرفقات العامة.
- تُستخدم نسخة الويب وAndroid العامة للمستخدمين.
